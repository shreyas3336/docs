## Main Command

### capx-adk

Create a new Next.js project with selected plugins.

```bash
capx-adk <project-name> [options]
```

**Arguments:**
- `project-name` - Name of the project directory to create (required)

**Options:**
- `--plugins <list>` - Comma-separated list of plugins to include
- `--use-pnpm` - Use pnpm as package manager
- `--use-yarn` - Use Yarn as package manager
- `--skip-install` - Skip automatic dependency installation
- `--eslint` - Include ESLint configuration
- `--no-eslint` - Skip ESLint configuration
- `-y, --yes` - Accept all defaults (non-interactive mode)
- `--dependency-strategy <strategy>` - Dependency resolution strategy (smart|highest|lowest|compatible)
- `--silent` - Suppress enhanced output

**Examples:**

```bash
# Interactive mode
capx-adk my-app

# With specific plugins
capx-adk my-app --plugins=vercel-ai,supabase

# Multiple plugins with package manager
capx-adk my-app --plugins=solana,firebase --use-pnpm

# Skip installation
capx-adk my-app --plugins=goat,evm --skip-install

# Accept defaults
capx-adk my-app -y
```

## Using with npx

The recommended way to use Capx ADK without global installation:

```bash
npx capx-adk@latest <project-name> [options]
```

**Examples:**

```bash
# Latest version
npx capx-adk@latest my-app

# Specific version
npx capx-adk@0.1.1 my-app

# With plugins
npx capx-adk@latest my-app --plugins=vercel-ai
```

## Plugin Commands

### `plugins list`

List all available plugins.

```bash
capx-adk plugins list [options]
```

**Example:**

```bash
# List all valid plugins
capx-adk plugins list
```

### `plugins show`

Show details for a specific plugin.

```bash
capx-adk plugins show <plugin>
```

**Arguments:**
- `plugin` - Name of the plugin to show details for

**Example:**

```bash
# Show vercel-ai plugin details
capx-adk plugins show vercel-ai

# Show supabase plugin details
capx-adk plugins show supabase
```
